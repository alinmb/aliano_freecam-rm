# Aliano FreeCam - Attachable Camera for FiveM

![Bannière du script aliano_freecam](https://i.ibb.co/HTvL8rdp/banner-aliano-freecam.png)

## Description

Aliano FreeCam is an advanced free camera script for FiveM that allows players to capture stunning in-game footage and screenshots from custom angles. Designed with content creators in mind, this tool provides complete control over camera positioning while maintaining fair gameplay boundaries.

### Key Features:

- **Customizable Camera Angles**: Adjust your viewpoint with precision on all axes
- **Movement Freedom**: Walk, drive, or perform actions while maintaining your custom camera perspective
- **Fair Play**: Built-in maximum radius to prevent metagaming/powergaming
- **Vehicle-Compatible**: Works seamlessly both on foot and in vehicles
- **Optimized Performance**: Lightweight and efficient with minimal resource usage
- **100% Standalone**: No dependencies required, compatible with any FiveM server
- **User-Friendly Controls**: Intuitive interface with on-screen instructions

## Installation

1. Download the latest release
2. Extract the `aliano_freecam` folder to your `resources` directory
3. Add `ensure aliano_freecam` to your server.cfg
4. Restart your server

## Usage

- **Activate/Deactivate**: Type `/acam` in chat
- **Movement Controls**:
  - Arrow Keys: Move camera up/down/left/right
  - Numpad +/-: Move camera forward/backward or mouse wheel
- **Camera Lock**: Press `H` to toggle camera lock (follows player movement)
- **Exit**: Press `X` to close the freecam
